# Validation Bar

## Evidence ladder

1. **Synthetic contracts:** unit tests establish support semantics, generic operators, counterexample handling, and no-target adapter boundaries.
2. **Tiny curated packet:** each attempt receives a complete grid, explicit trace/diagram, and post-answer YES/NO V&V.
3. **Curated 60 rediscovery:** historical high-level fitters remain quarantined; every result and failure remains recorded.
4. **Frozen disjoint 50:** freeze the learner before evaluating the 25 ARC1 + 25 ARC2 cohort.
5. **ARC3 shared-core experiments:** apply the same state/action/trace contracts to public real-game transitions.
6. **Fresh held-out cohorts:** pre-register before semantic inspection.

## No completion claim without

- complete predictions for every attempted test case;
- explicit all-cell post-answer V&V;
- source-pinned, reproducible receipts;
- failure-inclusive denominators;
- a blind generalization score separated from curated development;
- evidence that any promoted primitive transfers beyond its originating task/family.

P0001 clears only the first two rungs with `1/4` exact. P0002 supplies the requested initial 10+10 reporting cohort at `0/20`, and P0003 supplies a non-overlapping post-operator transfer cohort at `0/20`. All 44 attempts have complete predictions, durable diagrams, and post-answer YES/NO evidence, but these results remain intentionally far below the evidence required to claim that ARC1 or ARC2 has been solved.
